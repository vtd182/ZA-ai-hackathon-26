ProductSpec as Source of Truth ProductSpec là Trung tâm Sự thật

The agent establishes a business source of truth. When the scope changes (e.g., "Remove payment from MVP"), it automatically triggers impact analysis, requests your approval, and syncs the changes to both Figma designs and Jira tickets. Mọi thứ bắt đầu từ ProductSpec. Khi có thay đổi yêu cầu (VD: "Bỏ thanh toán khỏi MVP"), Agent sẽ tự động phân tích tác động, xin phê duyệt và cập nhật đồng bộ ra cả thiết kế Figma lẫn danh sách việc trên Jira.

Read-back Verification Kiểm chứng Ngược (Read-back)

Tool success is not enough. The agent explicitly reads back the state from Figma and Jira to guarantee that the artifacts actually match the current ProductSpec. Không chỉ "gọi API xong là thôi". Agent trực tiếp đọc lại dữ liệu từ Figma và Jira để kiểm chứng rằng các bản vẽ và công việc đã thực sự khớp với yêu cầu sản phẩm.

Local-First Execution Thực thi Local-First

Powered by a local SQLite outbox. No external writes happen without an immutable payload hash and explicit human approval. Vận hành bằng SQLite Outbox tại máy cá nhân. Không có bất kỳ thay đổi nào được đẩy ra ngoài nếu thiếu mã băm (Payload Hash) và sự phê duyệt từ con người.

Figma MCP with Zalo DS Figma MCP & Zalo DS

Our custom Figma Model Context Protocol ensures generated designs strict adherence to the Zalo Design System guidelines. Tích hợp giao thức Figma MCP đặc chế, đảm bảo mọi giao diện Agent tạo ra hoặc chỉnh sửa đều tuân thủ nghiêm ngặt Zalo Design System.
