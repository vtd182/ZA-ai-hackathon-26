macOS

Mở file .dmg, kéo DualMind vào thư mục Applications là xong phần cài. Vì đây là app hackathon mới build, chưa kịp ký (notarize) với Apple, nên lần đầu mở macOS sẽ hơi "làm khó" một chút — bình thường thôi, làm thế này:Mở file .dmg, kéo DualMind vào thư mục Applications là xong phần cài. Vì đây là app hackathon mới build, chưa kịp ký (notarize) với Apple, nên lần đầu mở macOS sẽ hơi "làm khó" một chút — bình thường thôi, làm thế này:

  1. Vào Finder → Applications, chuột phải vào DualMind → chọn Open.Vào Finder → Applications, chuột phải vào DualMind → chọn Open.
  2. Hộp thoại hiện ra thì bấm Open lần nữa. Từ lần sau click đúp mở như app thường.Hộp thoại hiện ra thì bấm Open lần nữa. Từ lần sau click đúp mở như app thường.

Nếu vẫn bị chặn, vào System Settings → Privacy & Security bấm Open Anyway. Hoặc mở Terminal gõ đúng một dòng này rồi mở lại app:Nếu vẫn bị chặn, vào System Settings → Privacy & Security bấm Open Anyway. Hoặc mở Terminal gõ đúng một dòng này rồi mở lại app:

xattr -dr com.apple.quarantine /Applications/DualMind.app

  2. Bấm + tạo cuộc trò chuyện mới, gõ một ý tưởng (ví dụ: "Mini App đặt suất ăn trưa cho văn phòng").Bấm + tạo cuộc trò chuyện mới, gõ một ý tưởng (ví dụ: "Mini App đặt suất ăn trưa cho văn phòng").

5. Bám ZDS hay để agent tự do?5. Bám ZDS hay để agent tự do?

Sau khi plugin kết nối, bạn chọn một trong hai kiểu — tùy bạn muốn giao diện chuẩn Zalo hay để agent thỏa sức:Sau khi plugin kết nối, bạn chọn một trong hai kiểu — tùy bạn muốn giao diện chuẩn Zalo hay để agent thỏa sức:

  • Dùng ZDS — mở page có component Zalo Mini App Framework/ZDS trong Figma, rồi bấm "Dùng Page đang mở". Agent sẽ vẽ bám đúng component/icon/style của Zalo.Dùng ZDS — mở page có component Zalo Mini App Framework/ZDS trong Figma, rồi bấm "Dùng Page đang mở". Agent sẽ vẽ bám đúng component/icon/style của Zalo.
  • Không dùng ZDS — mở một page trống, bấm "Không dùng ZDS". Agent tự do thiết kế theo ProductSpec, vẽ lên page đó, không bắt buộc mobile hay component Zalo.Không dùng ZDS — mở một page trống, bấm "Không dùng ZDS". Agent tự do thiết kế theo ProductSpec, vẽ lên page đó, không bắt buộc mobile hay component Zalo.

Đổi file/page trong Figma thì nhớ chọn lại trong DualMind — đây là "chốt chặn" để agent không lỡ tay ghi nhầm vào file của bạn.Đổi file/page trong Figma thì nhớ chọn lại trong DualMind — đây là "chốt chặn" để agent không lỡ tay ghi nhầm vào file của bạn.
