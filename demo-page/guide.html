Install & use DualMindCài đặt & sử dụng DualMind

Run it fully offline in under a minute, pick an AI brain, and optionally bridge Figma. No REST tokens required.Chạy hoàn toàn offline trong chưa đầy một phút, chọn "bộ não" AI, và kết nối Figma nếu muốn. Không cần REST token.

1. Install the desktop app1. Cài đặt ứng dụng

Grab the latest build from Releases. It ships the Figma runtime bundled — no extra install needed.Tải bản mới nhất ở Releases. Bản này đã đóng gói sẵn runtime Figma — không cần cài thêm gì.

macOS (unsigned hackathon build)macOS (bản hackathon chưa ký)

  1. Open DualMind-x.x.x-arm64.dmg and drag DualMind into Applications.Mở DualMind-x.x.x-arm64.dmg, kéo DualMind vào Applications.
  2. Don't double-click. Right-click (or Control-click) the app → Open → Open again in the dialog. It launches normally after that.Đừng click đúp. Chuột phải (hoặc Control-click) vào app → Open → bấm Open lần nữa ở hộp thoại. Các lần sau mở bình thường.
  3. If the app still won't open, clear the quarantine flag: xattr -dr com.apple.quarantine /Applications/DualMind.appNếu vẫn không mở được, gỡ cờ quarantine: xattr -dr com.apple.quarantine /Applications/DualMind.app

Windows

  1. Run DualMind-Setup-x.x.x.exe. If SmartScreen appears, choose More info → Run anyway.Chạy DualMind-Setup-x.x.x.exe. Nếu hiện SmartScreen, chọn More info → Run anyway.

2. First run — 100% offline, no key2. Lần chạy đầu — 100% offline, không cần key

Out of the box, DualMind uses the Mock · Offline provider — deterministic and free. You can go through the whole flow (Idea → Discovery → Decision → Delivery → kickoff artifacts) without any account or API key. Just type an idea and follow the guided choices.Ngay khi mở, DualMind dùng provider Mock · Offline — deterministic và miễn phí. Bạn có thể đi hết luồng (Ý tưởng → Khám phá → Quyết định → Delivery → sinh artifact) mà không cần tài khoản hay API key. Chỉ cần gõ ý tưởng và bấm theo các lựa chọn.

Tip: use the stepper's "Next step →" button to advance phases yourself, and the collapse/resize controls to keep the chat readable.Mẹo: dùng nút "Sang bước tiếp →" trên stepper để tự chuyển bước, và các nút thu gọn / kéo dãn khung chat để dễ đọc.

3. Pick an AI brain (optional)3. Chọn "bộ não" AI (tùy chọn)

Open Settings (gear icon or ⌘,) → Providers, or use the provider dropdown on the top bar. You can switch mid-session without losing context.Mở Cài đặt (icon bánh răng hoặc ⌘,) → Providers, hoặc dùng dropdown provider trên thanh trên. Có thể đổi giữa phiên mà không mất ngữ cảnh.

  • Mock · Offline — no setup, deterministic, great for demos.không cần cấu hình, deterministic, hợp để demo.
  • AgentRouter — recommended cloud brain. Open its Configure and paste your AgentRouter API key.bộ não cloud khuyến nghị. Mở Cấu hình và dán API key AgentRouter của bạn.
  • OpenAI / Gemini / Claude — paste the matching API key in Configure. Keys are stored in the OS keychain only.dán API key tương ứng vào Cấu hình. Key chỉ lưu trong keychain của hệ điều hành.
  • Codex — uses your local Codex CLI session; log in with the Codex CLI first and DualMind detects it.dùng phiên Codex CLI cục bộ; đăng nhập Codex CLI trước, DualMind sẽ tự nhận.

Cost-bearing providers require an explicit confirmation before the first paid turn.Các provider tính phí sẽ yêu cầu xác nhận rõ ràng trước lượt trả phí đầu tiên.

4. Connect Figma (optional)4. Kết nối Figma (tùy chọn)

No Figma? DualMind still ships Jira, Confluence and the PRD via a mock preview. To craft real, clickable ZDS prototypes, bridge Figma once. We never ask for a Figma REST token — the bundled runtime auto-starts locally and you import a dev plugin.Không có Figma? DualMind vẫn xuất đủ Jira, Confluence và PRD qua bản preview mock. Muốn craft prototype ZDS thật, bấm được, thì nối Figma một lần. Chúng tôi không hỏi Figma REST token — runtime đóng gói tự chạy cục bộ và bạn import một dev plugin.

Requires Figma Desktop (dev plugin import isn't available in the browser).Cần Figma Desktop (import dev plugin không chạy trên trình duyệt).

  1. In DualMind, open the Figma panel. The local runtime auto-starts (127.0.0.1).Trong DualMind, mở panel Figma. Runtime cục bộ tự khởi động (127.0.0.1).
  2. Click Open manifest — it reveals the bundled manifest.json (inside the app's Resources).Bấm Mở manifest — nó hiện file manifest.json đóng gói (trong Resources của app).
  3. In Figma Desktop: Plugins → Development → Import plugin from manifest… → choose that file, then run ZA Talk To Figma.Trong Figma Desktop: Plugins → Development → Import plugin from manifest… → chọn file đó, rồi chạy plugin ZA Talk To Figma.
  4. Back in DualMind, confirm the source:Quay lại DualMind, xác nhận nguồn:
    • Use this page on a ZDS component page → craft follows the Zalo Design System.Dùng Page đang mở ở trang chứa component ZDS → craft bám Zalo Design System.
    • Không dùng ZDS → free-creative: the agent designs from scratch, no ZDS reference needed.Không dùng ZDS → free-creative: agent tự thiết kế, không cần thư viện ZDS.

Switching Figma file/page requires allowlisting again — a guardrail so the agent never writes to the wrong place.Đổi file/page Figma thì phải allowlist lại — một guardrail để agent không bao giờ ghi nhầm chỗ.
