How to Setup & Use DualMind Hướng dẫn Cài đặt & Sử dụng DualMind

Everything you need to compile, run, and connect the agent to Figma. Mọi bước cần thiết để biên dịch, khởi chạy và kết nối Agent trực tiếp vào Figma.

1. Prerequisites & First-time setup 1. Môi trường & Khởi tạo ban đầu

To run DualMind locally from the source, ensure you have macOS with Figma Desktop, Node.js 22+, Go 1.24+, and Bun 1.3+. Run the following commands from the repository root: Để biên dịch DualMind từ mã nguồn, máy của bạn cần có macOS với Figma Desktop, Node.js 22+, Go 1.24+ và Bun 1.3+. Hãy mở Terminal tại thư mục gốc của dự án và chạy: 

./run.sh setup
./run.sh

The `setup` command automatically installs workspace dependencies, rebuilds the native SQLite module, builds the local Go runtime, and compiles the Figma plugin bundle. Lệnh `setup` sẽ tự động tải các thư viện cần thiết, build lại module SQLite, build Go runtime nội bộ và đóng gói plugin Figma.

2. Connect the Figma Plugin 2. Kết nối Plugin Figma

To allow the agent to read and draw in your Figma workspace, you must bridge it using our local plugin. No REST tokens required! Để Agent có quyền "đọc hiểu" và tự động vẽ giao diện vào không gian làm việc của bạn, hãy làm theo các bước sau (không cần cung cấp API token nguy hiểm):

  1. Trong DualMind, click vào tab Figma trên thanh công cụ.
  2. Xác nhận rằng Runtime local và Plugin build đang ở trạng thái sẵn sàng (ready).
  3. Bấm vào Open manifest.
  4. Mở app Figma Desktop, chọn Plugins → Development → Import plugin from manifest…
  5. Trỏ tới file `manifest.json` vừa được mở ra ở bước 3.
  6. Khởi chạy plugin ZA Talk To Figma ngay trong màn hình Figma của bạn.
  7. Quay lại DualMind và bấm nút Use this page để cấp quyền ghi cụ thể cho page này.

Once the plugin is connected, the UI will change to "Ready for preflight". If you switch Figma pages, you must re-allowlist the target to ensure the agent never overwrites the wrong file. Sau khi kết nối thành công, DualMind sẽ báo "Ready for preflight". Xin lưu ý: Mỗi khi bạn chuyển sang file hoặc page Figma khác, bạn phải bấm cấp quyền lại. Điều này đảm bảo Agent tuyệt đối không bao giờ ghi đè nhầm vào dữ liệu quan trọng của team.

3. Troubleshooting 3. Xử lý sự cố thường gặp

  • Lỗi "Runtime missing": Chạy lại lệnh `./run.sh setup` và kiểm tra xem Go / Bun đã được thêm vào biến môi trường PATH chưa.
  • Mãi kẹt ở "Waiting for plugin": Đảm bảo bạn đang chạy plugin "ZA Talk To Figma" ở cùng một cửa sổ Figma chứa file sandbox cần tương tác.
  • Lỗi cổng 1802 bị chiếm: Mở "Runtime console" từ hộp thoại setup, hệ thống có thể tái sử dụng một tiến trình cũ đang hoạt động ổn định trên cổng đó.
  • Electron hiển thị màn hình trắng: Tắt app, chạy `./run.sh build` sau đó chạy `./run.sh smoke`. Đảm bảo kết quả smoke test hiển thị `passed: true`.
