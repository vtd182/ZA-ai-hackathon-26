GETTING STARTED BẮT ĐẦU NHANH

How to Setup & Use DualMind Hướng dẫn Cài đặt & Sử dụng DualMind

Bypass Gatekeeper, configure the Codex CLI, and bridge your Figma workspace. Chi tiết cách vượt qua Gatekeeper của macOS, cài đặt môi trường Codex CLI và nối cầu trực tiếp vào Figma.

1. Install the Desktop App (macOS Gatekeeper) 1. Cài đặt Ứng dụng (Vượt lỗi Gatekeeper trên macOS)

Since DualMind is a newly compiled hackathon app, it does not have an Apple Developer Signature yet. macOS Gatekeeper will try to block it. Follow these steps: Vì DualMind là ứng dụng thi Hackathon được build "nóng hổi", nó chưa có chữ ký điện tử (Signature) của Apple Developer. Do đó, hệ thống bảo mật Gatekeeper của macOS sẽ chặn khi bạn click đúp mở app. Hãy làm theo các bước sau:

  1. Tải file DualMind-x.x.x-arm64.dmg từ trang Releases.
  2. Click đúp vào file `.dmg` để mở, sau đó kéo thả icon DualMind vào thư mục Applications.
  3. Mở thư mục Applications (Ứng dụng) trong Finder.
  4. ĐỪNG click đúp (Double-Click) vào app. Thay vào đó, hãy Chuột phải (Right-Click) hoặc giữ phím Control rồi click vào icon DualMind.
  5. Chọn Open (Mở) từ menu xổ xuống.
  6. Một bảng cảnh báo sẽ hiện ra, lúc này bạn tiếp tục bấm Open (Mở) một lần nữa. Từ các lần sau, bạn có thể click đúp mở app bình thường.

2. Set up Codex CLI (For Agentic Crafting) 2. Cài đặt Codex CLI (Bắt buộc để tự động vẽ Figma)

To allow DualMind to actively craft Figma components, you need the Codex CLI runtime running locally. Để tính năng đỉnh cao nhất của DualMind (tự động vẽ giao diện Figma) hoạt động, bạn cần cài đặt môi trường CLI cục bộ. 

# Mở Terminal và cài đặt global qua npm
npm install -g @zalo/codex-cli

# Sau khi cài xong, tiến hành đăng nhập
codex login

Once logged in, DualMind will automatically detect the Codex session and use it to execute advanced crafting tasks. Sau khi đăng nhập thành công ở Terminal, DualMind sẽ tự động nhận diện phiên làm việc và dùng nó để thực thi các tác vụ vẽ phức tạp.

3. Connect the Figma Plugin 3. Kết nối Plugin Figma (Model Context Protocol)

We do not ask for your Figma REST tokens. DualMind uses a local bridge plugin to ensure absolute security. Chúng tôi KHÔNG đòi hỏi Figma REST token nguy hiểm của bạn. DualMind sử dụng giao thức nối cầu cục bộ (Local Bridge) đảm bảo an toàn tuyệt đối:

  1. Trong app DualMind, click vào tab Figma trên thanh công cụ.
  2. Bấm vào Open manifest. Một thư mục chứa file `manifest.json` sẽ hiện ra.
  3. Mở app Figma Desktop, chọn Plugins → Development → Import plugin from manifest… và chọn file `manifest.json` đó.
  4. Khởi chạy plugin ZA Talk To Figma trong cửa sổ Figma của bạn.
  5. Quay lại app DualMind và bấm nút Use this page (Cấp quyền trang này) để cho phép Agent hoạt động.
