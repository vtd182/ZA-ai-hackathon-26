Install & run DualMindCài đặt & sử dụng DualMind

DualMind runs fully offline with no API key. This guide covers installation on macOS and Windows, configuring an AI provider, and — optionally — bridging Figma for live ZDS crafting.DualMind chạy hoàn toàn offline, không cần API key. Tài liệu này hướng dẫn cài đặt trên macOS và Windows, cấu hình provider AI, và tùy chọn kết nối Figma để craft ZDS trực tiếp.

1. Download the right files1. Tải đúng file trên GitHub Release

Open the latest release and download only the asset for your platform:Mở release mới nhất và tải đúng file cho hệ điều hành của bạn:

  • macOS (Apple Silicon): DualMind-<version>-arm64.dmgmacOS (Apple Silicon): DualMind-<version>-arm64.dmg
  • Windows: DualMind-Setup-<version>.exeWindows: DualMind-Setup-<version>.exe
  • To connect Figma: also download za-talk-to-figma-plugin.zipNếu muốn kết nối Figma: tải thêm za-talk-to-figma-plugin.zip

The latest.yml, *.blockmap and Source code assets are for auto-update and source; you do not need them to install.Các file latest.yml, *.blockmap và Source code phục vụ auto-update và mã nguồn — không cần để cài đặt.

2. Install2. Cài đặt

macOS

Open the .dmg and drag DualMind into Applications. This is an unsigned hackathon build, so Gatekeeper blocks the first launch. To open it:Mở file .dmg, kéo DualMind vào thư mục Applications. Đây là bản hackathon chưa ký (notarize) nên Gatekeeper sẽ chặn lần mở đầu. Cách mở:

  1. In Finder → Applications, right-click DualMind and choose Open.Trong Finder → Applications, chuột phải vào DualMind và chọn Open.
  2. Confirm Open in the dialog. Subsequent launches work with a normal double-click.Bấm Open ở hộp thoại xác nhận. Các lần sau mở bình thường bằng double-click.

If it is still blocked, go to System Settings → Privacy & Security → Open Anyway, or run this command in Terminal and reopen the app:Nếu vẫn bị chặn, vào System Settings → Privacy & Security → Open Anyway, hoặc chạy lệnh sau trong Terminal rồi mở lại app:

xattr -dr com.apple.quarantine /Applications/DualMind.app

Windows

Run DualMind-Setup-<version>.exe. If SmartScreen appears, choose More info → Run anyway, then launch DualMind from the Start Menu.Chạy DualMind-Setup-<version>.exe. Nếu SmartScreen cảnh báo, chọn More info → Run anyway, sau đó mở DualMind từ Start Menu.

3. Run it — offline, no key required3. Chạy thử — offline, không cần API key

DualMind defaults to the Mock · Offline provider — deterministic and free — so you can complete the entire flow without any account or key.DualMind mặc định dùng provider Mock · Offline — deterministic và miễn phí — nên bạn có thể chạy trọn luồng mà không cần tài khoản hay API key.

  1. Create a new conversation and describe a product idea.Tạo cuộc trò chuyện mới và mô tả một ý tưởng sản phẩm.
  2. Use “Next step →” on the stepper to move through Discovery and Decision, choosing the clickable options.Dùng “Sang bước tiếp →” trên thanh tiến trình để đi qua Khám phá và Quyết định, chọn các phương án có sẵn.
  3. Confirm the ProductSpec, then “Create kickoff package” and approve — you get Figma, a Jira backlog, a Confluence doc and a PRD, all traceable to one ProductSpec.Chốt ProductSpec, rồi bấm “Tạo kickoff package” và duyệt — bạn nhận được Figma, backlog Jira, tài liệu Confluence và PRD, tất cả truy vết về một ProductSpec.

4. Configure an AI provider (optional)4. Cấu hình provider AI (tùy chọn)

To use a real model, open Settings (gear icon or ⌘,) → Providers, or use the provider dropdown on the top bar. You can switch providers mid-session without losing context. API keys are stored in the OS keychain, never in the database.Để dùng model thật, mở Cài đặt (icon bánh răng hoặc ⌘,) → Providers, hoặc dùng dropdown provider trên thanh trên. Bạn có thể đổi provider giữa phiên mà không mất ngữ cảnh. API key được lưu trong keychain của hệ điều hành, không lưu trong cơ sở dữ liệu.

  • Mock · Offline — no configuration; deterministic, ideal for demos.không cần cấu hình; deterministic, phù hợp để demo.
  • AgentRouter — recommended cloud provider; open Configure and paste your AgentRouter API key.provider cloud khuyến nghị; mở Cấu hình và dán API key AgentRouter.
  • OpenAI / Gemini / Claude — paste the corresponding API key in Configure.dán API key tương ứng vào Cấu hình.
  • Codex — uses your local Codex CLI session; log in with the Codex CLI and DualMind detects it.dùng phiên Codex CLI cục bộ; đăng nhập Codex CLI và DualMind sẽ tự nhận.

Paid providers ask for an explicit confirmation before the first billable turn.Các provider tính phí sẽ yêu cầu xác nhận trước lượt trả phí đầu tiên.

5. Connect Figma (optional)5. Kết nối Figma (tùy chọn)

Without Figma, DualMind still produces the Jira backlog, Confluence doc and PRD via a mock preview. To generate real, clickable ZDS prototypes, connect Figma once. No Figma REST token is required — the app bundles a local runtime that starts automatically; you only import a development plugin. Figma Desktop is required (development plugin import is not available in the browser).Không có Figma, DualMind vẫn xuất backlog Jira, tài liệu Confluence và PRD qua bản preview mock. Để tạo prototype ZDS thật và bấm được, hãy kết nối Figma một lần. Không cần Figma REST token — app đã nhúng sẵn một runtime cục bộ tự khởi động; bạn chỉ cần import một development plugin. Bắt buộc dùng Figma Desktop (bản trình duyệt không import được plugin development).

  1. Unzip za-talk-to-figma-plugin.zip; it contains manifest.json and a dist/ folder.Giải nén za-talk-to-figma-plugin.zip — bên trong có manifest.json và thư mục dist/.
  2. In Figma Desktop: Plugins → Development → Import plugin from manifest… and select that manifest.json.Trong Figma Desktop: Plugins → Development → Import plugin from manifest… và chọn file manifest.json đó.
  3. Run the ZA Talk To Figma plugin and keep its window open.Chạy plugin ZA Talk To Figma và giữ cửa sổ plugin mở.
  4. Back in DualMind, open the Figma panel and confirm the status shows connected.Quay lại DualMind, mở panel Figma và kiểm tra trạng thái đã kết nối.

Choose a design modeChọn chế độ thiết kế

  • Use ZDS — open a page containing Zalo Design System components, then click “Use this page”. The agent crafts strictly against those components, icons and styles.Dùng ZDS — mở page chứa component Zalo Design System, rồi bấm “Dùng Page đang mở”. Agent craft bám đúng component, icon và style đó.
  • Free-creative — open a blank page and click “Không dùng ZDS”. The agent designs freely from the ProductSpec, with no ZDS reference required.Không dùng ZDS — mở page trống và bấm “Không dùng ZDS”. Agent thiết kế tự do theo ProductSpec, không cần thư viện ZDS.

Switching the Figma file or page requires re-selecting the source in DualMind — a guardrail so the agent never writes to the wrong place.Đổi file hoặc page Figma thì cần chọn lại nguồn trong DualMind — một guardrail để agent không ghi nhầm chỗ.

6. Troubleshooting6. Xử lý sự cố

  • macOS won't open the app: use right-click → Open, “Open Anyway” in Privacy & Security, or the xattr command in step 2.macOS không mở được app: dùng chuột phải → Open, “Open Anyway” trong Privacy & Security, hoặc lệnh xattr ở mục 2.
  • Figma can't see the plugin: ensure you are on Figma Desktop and imported the extracted manifest.json.Figma không thấy plugin: đảm bảo dùng Figma Desktop và đã import đúng manifest.json sau khi giải nén.
  • DualMind shows Figma not connected: run the ZA Talk To Figma plugin and keep its window open while generating designs.DualMind báo chưa kết nối Figma: chạy plugin ZA Talk To Figma và giữ cửa sổ plugin mở trong lúc tạo design.
  • Figma crafting takes a while: a real design can take a few minutes — do not close the app or plugin during “Figma craft”.Figma craft hơi lâu: một design thật có thể mất vài phút — không đóng app hay plugin khi đang chạy “Figma craft”.
  • Provider/API error: switch back to Mock · Offline to demo the local flow, then reconfigure the provider in Settings.Lỗi provider/API: quay về Mock · Offline để demo luồng local, rồi cấu hình lại provider trong Cài đặt.
