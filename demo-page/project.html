PROJECT DEEP DIVE PHÂN TÍCH CHUYÊN SÂU

How the Kickoff Agent transforms your product lifecycle. Cách Kickoff Agent định hình lại vòng đời sản phẩm của bạn.

An in-depth look at the architecture, workflow, and engineering decisions behind the Zalo Product Kickoff Agent. Một góc nhìn sâu sắc hơn về kiến trúc hệ thống, luồng công việc và các quyết định kỹ thuật đằng sau Zalo Product Kickoff Agent.

1. The Context Switching Problem 1. Vấn nạn Chuyển đổi Ngữ cảnh

In modern product development, information is highly fragmented. Product Managers write requirements in Docs. Designers create visuals in Figma. Developers track tasks in Jira. When it's time to "kick off" a sprint, ensuring all these platforms are perfectly synchronized is a manual, error-prone nightmare. Trong quy trình phát triển sản phẩm hiện đại, thông tin thường xuyên bị phân mảnh. Product Manager viết Requirement trên Docs. Designer vẽ giao diện trên Figma. Developer quản lý Task trên Jira. Mỗi lần khởi động (kick-off) một tính năng mới, việc giữ cho tất cả các nền tảng này đồng bộ là một cơn ác mộng thủ công và đầy rẫy sai sót.

2. The Infinity Canvas Solution 2. Giải pháp Bảng vẽ Vô cực

Instead of building another chatbot sidebar, we built a Spatial Infinity Canvas. You interact with AI agents visually. You drop a Figma link onto the canvas, ask the agent to extract the UI components, and the agent visually maps out the Jira tickets right in front of you. Thay vì đóng khung trong một thanh Chatbot chật hẹp, chúng tôi mang đến một Bảng vẽ Vô cực (Infinity Canvas). Tại đây, bạn tương tác trực quan với các Agent AI. Chỉ cần thả một đường dẫn Figma vào bảng vẽ, ra lệnh bóc tách component, và chiêm ngưỡng các thẻ Jira được Agent sắp xếp tự động ngay trước mắt.

3. Secure, Local-First Architecture 3. Kiến trúc Bảo mật & Dữ liệu Cục bộ (Local-First)

Enterprise data is sensitive. The Kickoff Agent operates as a local Electron desktop application. We use a Local SQLite Outbox pattern for all state management. When the agent proposes creating 15 Jira tickets, it doesn't just fire API calls blindly. It prepares the payloads and pauses for Human Approval. Dữ liệu doanh nghiệp là tài sản vô giá. Vì vậy, Kickoff Agent được thiết kế dưới dạng ứng dụng Desktop vận hành hoàn toàn độc lập. Chúng tôi ứng dụng kiến trúc SQLite Outbox cho mọi trạng thái hệ thống. Khi Agent đề xuất tạo 15 thẻ Jira mới, nó không gọi API ngay lập tức, mà chuẩn bị sẵn toàn bộ dữ liệu (Payload) và đợi Bạn trực tiếp phê duyệt.

4. Figma MCP Integration 4. Sức mạnh của Figma MCP

Our custom Figma Model Context Protocol (MCP) server bridges the gap between raw pixel data and semantic meaning. The agent doesn't just "look at an image" – it deeply inspects the Figma node tree to understand the design system tokens, text styles, and layout structures to generate pixel-perfect specifications. Máy chủ Figma MCP (Model Context Protocol) do chúng tôi phát triển là cầu nối hoàn hảo giữa dữ liệu điểm ảnh thô và ngữ nghĩa thiết kế. AI không chỉ "nhìn lướt qua một bức ảnh" - nó đi sâu vào phân tích cây cấu trúc của Figma để hiểu cặn kẽ về Design System, Text Styles, từ đó xuất ra tài liệu chuẩn xác đến từng chi tiết.
