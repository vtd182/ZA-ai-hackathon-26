1. A controlled lifecycle, guided by choices1. Vòng đời có kiểm soát, dẫn bằng lựa chọn

DualMind is not an open-ended chatbot — it runs a lifecycle state machine: Idea → Discovery → Decision → Delivery. Instead of aimless chat, it locks scope with three clickable clarifications, then a small set of MVP options. A deterministic "next step" control lets you advance the phase yourself, so the flow never stalls waiting for the model to volunteer.DualMind không phải chatbot mở — nó chạy một cỗ máy trạng thái: Ý tưởng → Khám phá → Quyết định → Delivery. Thay vì chat lan man, nó khóa scope bằng ba clarification bấm được, rồi vài phương án MVP. Nút "Sang bước tiếp" deterministic cho phép bạn tự chuyển bước, nên luồng không bao giờ kẹt chờ model tự quyết.

2. Infinity Canvas & self-critique2. Bảng vẽ Vô cực & tự phản biện

The user flow is laid out with a semantic dagre layout, then treated as a directed graph. A Logical Flow Linter flags dead ends, branches without decisions, and infinite loops right on the canvas. Select any node and chat about just that region — logic gets bulletproof before design or code.User flow được bố cục bằng thuật toán dagre ngữ nghĩa, rồi coi như một đồ thị có hướng. Logical Flow Linter tô đỏ ngõ cụt, nhánh thiếu điều kiện và vòng lặp vô tận ngay trên canvas. Chọn một node bất kỳ và chat đúng về vùng đó — logic được bít kín trước khi thiết kế hay code.

3. One ProductSpec → four artifacts3. Một ProductSpec → bốn artifact

Promote the canvas and every semantic node becomes a traceable requirement + screen inside a single ProductSpec — the confirmed source of truth. From it, DualMind generates a Figma design, a Jira backlog, a Confluence doc and a Markdown PRD. You can review the task decomposition and the document in-app before anything is exported or pushed.Promote canvas và mỗi node semantic thành một requirement + screen có truy vết trong một ProductSpec duy nhất — nguồn sự thật đã chốt. Từ đó, DualMind sinh thiết kế Figma, backlog Jira, tài liệu Confluence và PRD Markdown. Bạn có thể xem lại phân rã task và tài liệu ngay trong app trước khi export hay đẩy đi.

4. The ZDS Figma craft worker4. Craft worker Figma chuẩn ZDS

An agentic craft worker (driven through a local Figma MCP runtime) reads Zalo Design System components and composes real, clickable prototypes — instantiating ZDS controls, wiring navigation between screens, and iterating with screenshot-based self-review. No Figma connected? It degrades gracefully to a mock preview so Jira, Confluence and the PRD still ship.Craft worker agentic (điều khiển qua runtime Figma MCP nội bộ) đọc component Zalo Design System và dựng prototype thật, bấm được — instantiate ZDS control, nối điều hướng giữa các màn, và tự review bằng screenshot qua từng vòng. Chưa nối Figma? Hệ thống tự hạ mượt xuống bản preview để Jira, Confluence và PRD vẫn ra đủ.

5. Governed writes — approval, hash, read-back5. Ghi có kiểm soát — duyệt, hash, read-back

Nothing goes out silently. Every external write is staged into an execution outbox, carries an immutable payload hash, and waits for your approval. Change the payload and the approval is void. After writing, each target is read back to confirm it landed — and targets execute independently, so a Figma hiccup never blocks the Jira or PRD write.Không gì âm thầm rời đi. Mọi ghi ra ngoài được đưa vào execution outbox, gắn payload hash bất biến, và chờ bạn duyệt. Đổi payload là mất duyệt. Sau khi ghi, mỗi target được đọc lại để xác nhận đã vào — và các target chạy độc lập, nên một trục trặc Figma không bao giờ chặn ghi Jira hay PRD.

6. Local-first & provider-agnostic6. Local-first & đa provider

DualMind is an Electron desktop app that stores all execution memory in local SQLite — synthetic/sandbox data only, no cloud round-trip for state. It runs fully offline on a deterministic mock (no API key), or you can switch between Mock, Codex, OpenAI, Gemini, Claude and AgentRouter mid-session without losing context. Credentials live in the OS keychain, never in SQLite or the renderer.DualMind là app desktop Electron lưu toàn bộ execution memory trong SQLite cục bộ — chỉ dữ liệu synthetic/sandbox, không round-trip cloud cho state. Chạy hoàn toàn offline bằng mock deterministic (không cần API key), hoặc đổi giữa Mock, Codex, OpenAI, Gemini, Claude, AgentRouter ngay giữa phiên mà không mất ngữ cảnh. Credential nằm trong keychain của OS, không lưu trong SQLite hay renderer.
