How the Kickoff Agent transforms your product lifecycle. Cách Kickoff Agent chuyển đổi vòng đời sản phẩm của bạn.

An in-depth look at the architecture, workflow, and engineering decisions behind the Zalo Product Kickoff Agent. Một cái nhìn sâu hơn về kiến trúc hệ thống, luồng công việc và các quyết định kỹ thuật đằng sau Zalo Product Kickoff Agent.

1. The Context Switching Problem 1. Vấn nạn Chuyển đổi Ngữ cảnh (Context Switching)

In modern product development, information is highly fragmented. Product Managers write requirements in Docs. Designers create visuals in Figma. Developers track tasks in Jira. When it's time to "kick off" a sprint, ensuring all these platforms are perfectly synchronized is a manual, error-prone nightmare. Trong phát triển sản phẩm hiện đại, thông tin thường xuyên bị phân mảnh. PM viết Requirement trên Docs. Designer vẽ UI trên Figma. Dev quản lý Task trên Jira. Mỗi lần "kick off" một tính năng mới, việc giữ cho tất cả các nền tảng này đồng bộ là một ác mộng phải làm bằng tay và rất dễ sai sót.

2. The Spatial Agent Solution 2. Giải pháp Không gian Agent (Spatial Canvas)

Instead of building another chatbot sidebar, we built a Spatial Canvas. Using `tldraw`, you interact with AI agents visually. You drop a Figma link onto the canvas, ask the agent to extract the UI components, and the agent visually maps out the Jira tickets right in front of you. Thay vì làm một khung Chatbot Sidebar nhàm chán nữa, chúng tôi đã tạo ra một Bảng vẽ Không gian (Spatial Canvas). Bằng cách sử dụng `tldraw`, bạn tương tác với các Agent AI một cách trực quan. Kéo thả link Figma vào bảng vẽ, ra lệnh cho Agent bóc tách component, và xem Agent vẽ các thẻ Jira ra ngay trước mắt bạn.

3. Secure, Local-First Architecture 3. Kiến trúc Bảo mật & Local-First

Enterprise data is sensitive. The Kickoff Agent operates as a local Electron desktop application. We use a Local SQLite Outbox pattern for all state management. When the agent proposes creating 15 Jira tickets, it doesn't just fire API calls blindly. It prepares the payloads and pauses for Human Approval. Dữ liệu doanh nghiệp là vô cùng nhạy cảm. Vì vậy Kickoff Agent hoạt động như một ứng dụng Desktop (Electron) hoàn toàn nội bộ. Chúng tôi dùng kiến trúc SQLite Outbox để quản lý trạng thái. Khi Agent đề xuất tạo 15 Jira tickets, nó không gọi API ngay lập tức, mà chuẩn bị sẵn Payload và chờ Người dùng phê duyệt.

4. Figma MCP Integration 4. Sức mạnh của Figma MCP

Our custom Figma Model Context Protocol (MCP) server bridges the gap between raw pixel data and semantic meaning. The agent doesn't just "look at an image" – it deeply inspects the Figma node tree to understand the design system tokens, text styles, and layout structures to generate pixel-perfect specifications. Máy chủ Figma MCP (Model Context Protocol) tùy biến của chúng tôi là cầu nối giữa dữ liệu pixel thô và ý nghĩa ngữ nghĩa. AI không chỉ "nhìn vào bức ảnh" - nó đi sâu vào phân tích các node của Figma để hiểu design system, text styles, từ đó xuất ra tài liệu chuẩn chỉnh nhất.
